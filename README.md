# zkPrompt

zkPrompt is a **ZK-powered trusted AI relay** with native **[Rig](https://github.com/0xPlaygrounds/rig)** integration.

Today, many AI applications rely on opaque relay services before requests reach the actual model provider. Users and downstream applications have no reliable way to verify whether a relay truly forwarded the original request to the intended model and provider.

A relay may silently:

- Replace the requested model with a different one
- Modify model parameters
- Rewrite or inject prompts
- Return responses that were not generated by the claimed model endpoint

zkPrompt brings verifiability to the AI relay layer. By combining zkTLS-style proofs with a Rig-compatible client, zkPrompt enables applications to cryptographically verify that requests were forwarded to the expected AI provider and model endpoint, while preserving the privacy of sensitive prompt contents.

## Why zkPrompt?

Traditional AI gateways require trust. With zkPrompt, applications can verify:

- The request reached the intended AI provider
- The request was forwarded to the expected model endpoint
- The relay did not tamper with the request in transit
- Sensitive prompts remain private
- Proofs can be independently verified by third parties

## Key Features

- zkTLS-based request verification
- Verifiable AI relay architecture
- Native Rig integration
- Privacy-preserving prompt handling
- Cryptographic proof generation
- Compatible with existing LLM workflows

## Vision

zkPrompt aims to become the trust layer between AI applications and model providers.

Instead of blindly trusting relay services, developers can obtain cryptographic evidence that an AI request was delivered to the intended provider while keeping proprietary prompts confidential.

**Trust AI. Verify everything.**

## Quick Start

Copy [`.env_tmplate`](.env_tmplate) to `.env` and fill in the required values, then start the local relay:

```bash
cargo run -p proxy -- --forward dashscope.aliyuncs.com --port 9100
```

In another terminal, run the example:

```bash
cargo run -p example
```

The relay upstream host must match the target model provider.
